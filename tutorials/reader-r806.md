# 从阅读、摘录到回看原文

这段原文我想留下来，自己想到的事也不想丢。下面这条会从选书和开始学习，一直走到保存记录、展开笔记，再顺着笔记回到原文。

![页芽阅读器完整操作样片](../assets/tutorials/reader-r806/cover.svg)

https://github.com/user-attachments/assets/b8c1a79b-0ed6-4a39-8d66-54d9b4a05139

录制界面为 **r806 / Windows 10**，使用虚拟机中的隔离示例项目与已有书籍；用时和记录按实际操作保存。当前公开安装包版本请以[首页](../README.md#下载安装)为准。此条为首条教学样片，后续教程在审阅后逐步更新。

| 步骤 | 操作 |
| --- | --- |
| 1 · 选好书 | 在首页选择阅读项目与已关联电子书的书目。 |
| 2 · 开始学习 | 点击“开始学习”。 |
| 3 · 阅读器自动出现 | 保留主窗，等待独立页芽阅读器打开当前书籍。 |
| 4 · 目录与翻页 | 打开左侧目录，选章节，再正常翻页或滚动。 |
| 5 · 选择原文 | 拖选一段想留下的原文，打开摘录与心得入口。 |
| 6 · 写下并保存心得 | 输入具体理解或疑问，点击“保存心得”，确认已保存到本地。 |
| 7 · 返回页芽 | 点击“返回页芽”，回到主窗；需要时点击主窗首页。 |
| 8 · 结束本次学习 | 点击“结束并记录”。 |
| 9 · 核对记录 | 核对实际进度、用时与备注，再点击“结束并保存”。 |
| 10 · 保存后自动关闭 | 等待记录生效，原阅读器会自动关闭。 |
| 11 · 进入记录 | 在页芽点击“记录”。 |
| 12 · 打开笔记 | 切换到“笔记”，查找刚刚保存的标题。 |
| 13 · 展开这条笔记 | 查看摘录、自己的心得及来源。 |
| 14 · 从对应卡片返回原文 | 点击这条笔记卡片内的“回原文 ↗”。 |
| 15 · 阅读器打开并定位 | 等待独立阅读器重新打开对应原文位置。 |
| 16 · 区分查阅与学习 | 这里只是查阅原文，没有自动新增一轮学习记录；需要学习时再主动开始。 |
